# expertiz_sistemleri

Expertiz sistemleri tek repo catisi.

## Klasorler

- `musteri_paneli/`: Yerimebak AI backend, Docker servisleri, musteri paneli, vitrin, scraper, market coverage ve Chrome eklentisi.
- `expertiz_paneli/`: Flutter admin/personel/ekspertiz paneli.

## Calisma Notlari

- Docker komutlari `musteri_paneli/` icinden calistirilir.
- Flutter komutlari `expertiz_paneli/` icinden calistirilir.
- Bu kok klasor tek Git reposudur; alt klasorlerde ayri Git deposu bulunmaz.
